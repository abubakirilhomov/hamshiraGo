# HamshiraGo — Конкурентный анализ (2026-04-15)

## Прямые конкуренты в Узбекистане

### OVI.uz — главный конкурент
- Платформа записи к врачу + видеоконсультации + чат
- OVI Pro для врачей, сотни клиник
- **Нет медсестёр на дом** — наше преимущество
- https://ovi.uz/en

### DMED (государственная)
- Единая электронная система здравоохранения (37 млн граждан)
- MED-ID, электронные рецепты, запись к врачу
- Не конкурент напрямую, но задаёт стандарт

## Наше преимущество vs OVI.uz

| Функция | HamshiraGo | OVI.uz |
|---------|-----------|--------|
| Медсестра на дом | Есть | Нет |
| Запись к врачу | Есть | Есть |
| Видео-консультации | Есть | Есть |
| AI-ассистент (Salomat) | Есть | Нет |
| Клиники (CEO portal) | Есть | Есть |
| Рецепты | Есть | Частично |
| Оплата Payme/Click | Есть | Есть |

**Главное:** медсестра на дом + AI Salomat + клиники + врачи — всё в одном.

## Roadmap: что добавлять

### TIER 1 — Монетизация
1. Доставка лекарств (замыкает цепочку: Salomat → врач → рецепт → лекарства → медсестра)
2. Лабораторные анализы (медсестра на дом забирает кровь)
3. Подписка/членство (скидки на все услуги)
4. Интеграция страховок
5. Моментальный вывод средств (same-day pay для медиков)

### TIER 2 — Конкурентное преимущество
6. Автоматическая верификация документов медиков
7. Health Articles / Blog (SEO)
8. Семейный аккаунт
9. AI symptom checker (расширение Salomat)
10. Расписание медиков (shift templates)

### TIER 3 — Долгосрочное
11. Wearable интеграция (Apple Health / Google Fit)
12. E-рецепты с QR (DMED совместимость)
13. Мультиязычность (eng)
14. Корпоративные контракты (B2B)
15. Gamification для медиков (бейджи, уровни, бонусы)
